UC3 - Desenvolver Aplicações Desktop em Python

Criação de interfaces gráficas e aplicações desktop funcionais com Python

📌 Objetivo da UC

Desenvolver aplicações desktop utilizando Python, com foco na criação de interfaces gráficas, manipulação de eventos e integração com dados, visando melhorar a experiência do usuário.

🧠 Conteúdos estudados

  • Introdução a interfaces gráficas
  • Biblioteca Tkinter (ou equivalente)
  • Eventos e interações do usuário
  • Botões, inputs e janelas
  • Organização de layouts
  • Conexão com dados locais

💡 O que aprendi

Nesta unidade, aprendi a transformar código Python em aplicações visuais interativas, entendendo como estruturar interfaces e melhorar a usabilidade de sistemas desktop.
