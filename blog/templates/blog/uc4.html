📌 Objetivo da UC

Desenvolver aplicações web responsivas utilizando Python no backend, integrando tecnologias de front-end para criação de interfaces dinâmicas, funcionais e adaptáveis a diferentes dispositivos.

🧠 Conteúdos estudados

  • HTML, CSS e responsividade
  • Integração front-end e back-end
  • Consumo e organização de dados
  • Boas práticas de UI/UX
  • Introdução a APIs

💡 O que aprendi

Nesta unidade, aprendi a desenvolver interfaces web responsivas, entendendo como o backend em Python se conecta ao frontend, permitindo criar aplicações mais completas e dinâmicas.
