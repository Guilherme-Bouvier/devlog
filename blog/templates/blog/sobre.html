Sobre o Projeto

O DEV BLOG é uma aplicação web desenvolvida como projeto final da formação em desenvolvimento de software, com o objetivo de aplicar na prática os conhecimentos adquiridos durante a jornada de aprendizado em programação e desenvolvimento web. A plataforma foi criada para publicação, organização e apresentação de conteúdos relacionados à tecnologia e programação, permitindo que usuários naveguem por artigos, categorias e informações estruturadas de forma simples e intuitiva. O projeto representa a construção de uma aplicação completa, passando pelas etapas de planejamento, desenvolvimento, organização dos dados, criação das interfaces e preparação para publicação em ambiente de produção.

Objetivo

O principal objetivo do DEV BLOG é disponibilizar um ambiente organizado para publicação e gerenciamento de conteúdos, proporcionando uma experiência agradável para visitantes e administradores. A aplicação busca demonstrar como diferentes componentes de um sistema web trabalham juntos, permitindo recursos como visualização de artigos, categorização de conteúdos, pesquisa, paginação e gerenciamento de informações. Além do funcionamento como plataforma de conteúdo, o projeto tem como finalidade consolidar conhecimentos de desenvolvimento de software, aplicando conceitos utilizados na criação de aplicações reais.

Arquitetura

O sistema foi desenvolvido utilizando o padrão arquitetural MVT (Model, View, Template), seguindo a estrutura proposta pelo framework Django. A camada Model é responsável pela definição e organização dos dados da aplicação. A camada View controla as regras de negócio e o processamento das informações. Já os Templates são responsáveis pela apresentação dos dados ao usuário através de páginas dinâmicas. Essa organização permite manter o projeto estruturado, facilitando a manutenção, evolução e inclusão de novas funcionalidades.

Desenvolvimento

Durante o desenvolvimento foram implementadas funcionalidades essenciais para uma aplicação web moderna, incluindo gerenciamento de artigos, categorias, upload de imagens, sistema de pesquisa, paginação, integração com banco de dados e disponibilização da aplicação em ambiente online. O desenvolvimento do DEV BLOG representa a aplicação prática de conceitos de programação, banco de dados e desenvolvimento web, resultando em uma solução completa, organizada e preparada para futuras melhorias.
