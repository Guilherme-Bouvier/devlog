UC2 - Desenvolver Algoritmos em Python

Introdução à linguagem Python e construção de algoritmos estruturados

📌 Objetivo da UC

Capacitar o aluno a desenvolver algoritmos utilizando a linguagem Python, aplicando lógica de programação na resolução de problemas computacionais de forma estruturada e eficiente.

🧠 Conteúdos estudados

  • Sintaxe básica do Python
  • Tipos de dados (int, float, string, bool)
  • Entrada e saída de dados (input / print)
  • Estruturas condicionais (if, elif, else)
  • Estruturas de repetição (for, while)
  • Listas, tuplas e dicionários
  • Funções em Python

💡 O que aprendi

Nesta unidade, aprendi a transformar lógica de programação em código Python, desenvolvendo soluções mais organizadas, reutilizáveis e próximas de aplicações reais.
