UC5 - Planejar e Desenvolver Websites Utilizando o Framework Django

Desenvolvimento completo de aplicações web com arquitetura MVT

📌 Objetivo da UC

Planejar e desenvolver aplicações web completas utilizando o framework Django, aplicando arquitetura MVT, manipulação de banco de dados, autenticação de usuários, criação de rotas, templates e boas práticas de desenvolvimento web.

🧠 Conteúdos estudados

  • Arquitetura MVT (Model - View - Template)
  • Criação de projetos Django
  • Models e banco de dados relacional
  • Admin Django
  • Sistema de rotas (URLs)
  • Views e templates
  • Autenticação e controle de usuários
  • CRUD completo (Create, Read, Update, Delete)

💡 O que aprendi

Nesta unidade, desenvolvi a capacidade de construir aplicações web completas, estruturadas e escaláveis utilizando Django. Este conhecimento foi aplicado diretamente no desenvolvimento do DEV BLOG, onde implementei funcionalidades como listagem de artigos, categorias, detalhes de postagens e organização do sistema em arquitetura MVT.

🚀 Projeto aplicado

O DEV BLOG foi desenvolvido como projeto final da UC5, integrando todos os conhecimentos adquiridos ao longo do curso, desde lógica de programação até desenvolvimento web completo.
